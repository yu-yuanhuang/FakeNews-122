# GEXF Studio — 研究網絡圖譜編輯器

本專案為純前端靜態網頁，無須伺服器、資料庫、Node.js 安裝或外部 CDN。可離線開啟 `index.html`，也可直接放置 GitHub Pages。所有互動及匯出皆在瀏覽器端完成。

## 使用方式

1. 解壓縮，在資料夾內開啟 `index.html`。
2. 點選「匯入 GEXF / JSON」，載入 R、Gephi 或其他工具匯出的靜態 GEXF 網絡。
3. 直接拖曳節點移動；拖曳空白區平移；滾輪縮放；點選節點或連線調整右側屬性。
4. 左側可選擇數值欄位對應節點大小、類別欄位對應群集顏色、任意欄位對應標題、線條粗細與透明度、方向與最低顯示權重。
5. 每個群集可以選擇不同顏色及網點。預設提供紅、綠、藍等莫蘭迪識別色。
6. 匯出 GEXF、SVG、PNG 或專案 JSON。JSON 保留完整工作階段（包括視覺映射、色彩及網點設定），可再次匯入。

## GitHub Pages 部署

將解壓後的 `index.html`、`style.css`、`app.js`、`sample.js`、`sample.gexf` 及 `.nojekyll` 一起上傳至 GitHub repository 根目錄。前往 repository「Settings → Pages」，選擇 `Deploy from a branch`、`main`、`/(root)`，儲存並等待 GitHub Pages 提供網站網址。

如希望訪客開啟網站即看到你的正式分析成果，把正式 GEXF 另存為 `network.gexf`，一併放在根目錄。HTTP(S) 網頁會優先載入這個檔案；不存在時顯示內建範例。若本機直接雙擊 HTML，使用匯入功能載入正式 GEXF。已儲存的本機工作階段優先於預設資料，可用「載入範例」或重新匯入檔案切換。

## 網點樣式

細點、粗點、右斜線、左斜線、交叉斜線、水平線、垂直線、方格、圓環、菱形，共 10 種紋理，另有純色（無網點）。各群集與各個節點皆可單獨設定。SVG／PNG 保留紋理。GEXF 沒有通用網點標準，故另存 `Studio pattern`、`Studio outline` 等屬性；其他工具可能不直接顯示紋理，在本編輯器內重新匯入可恢復。JSON 為最完整的保存格式。

## 資料與分析注意事項

- 內建範例使用正規化後 122 篇 Fake News 文獻的作者關鍵字 DE，最低詞頻 3，得到 30 節點及 163 條共現線。範例的群集為獨立的貪婪模組度合併、布局為獨立力導向計算，得到 4 群，**並非先前 R 的正式 Louvain 分群結果**；請匯入實際產出的正式 GEXF，以保持論文分群一致。
- 預設五級連線寬度依原始權重 1、2、3、4–5、≥6 設定；視覺線寬不會改變原始權重。
- 手動移動、視覺映射、篩選與布局不會重新計算中心性。明確修改資料屬性、權重、方向則會改變匯出的資料；若要維持計量分析一致性，應另存視覺版本並保留原始分析檔。
- 編輯器支援靜態 GEXF、有向／無向／雙向及節點/連線屬性；不支援動態時段或 spells、完整外部工具特有擴充。GEXF 重輸出保留基本資料、欄位及可支援的視覺資訊，並非原 XML 的無損複製。
- 匯出 SVG 為向量圖；PNG 為當前畫布、寬 3200 px。需要 PDF 時可在向量繪圖軟體或瀏覽器將 SVG 另存為 PDF。
- GitHub Pages 若設為公開，放入 repository 的 `network.gexf` 也可能被公開取得。不要將未公開或敏感研究資料置於公開 repository；本地匯入則不會將檔案送至伺服器。
